# Reaction_Speed_Test

This web app is designed to record how reaction speed differs based on different colours being shown to a user.
Begin the test and it will run 10 trials, each with a different colour from our set shown in random order. Afterwards the result will be stored in a csv file where the colour's hex code and the reaction time for it will be recorded as a pair, this can be downloaded for use in analytics.

This app was made for the Week 4 homework of module SCCM5410 at Lancaster University by Team One from the lab session (Grp-HCI-SCCM5410-Lab-P01/09)
